Course Syllabus Summary

ITC C201 is a 3-unit course (2 hours lecture, 3 hours laboratory) that introduces database concepts, design, creation and management using Oracle Database SQL. It ends with a project in which students design and demonstrate a normalized database solution for a business.

Prelim (Weeks 1–6)

Database fundamentals, ERDs, supertypes/subtypes, Oracle SQL Data Modeler.

Midterm (Weeks 7–12)

Oracle APEX, normalization (1NF–3NF), DDL, constraints, INSERT / UPDATE / DELETE.

Final (Weeks 13–18)

WHERE, LIKE, IN, BETWEEN, group functions, inner / outer / self / cross / natural joins.

Grading: Prelim 30% · Midterm 30% · Final 40%. Each term = class standing 70% + major exam 30%. Full summary, p. 4

Learning Reflection

What important knowledge and skills did I learn?

I learned to draw ERDs in SQL Data Modeler, including supertype and subtype entities, and to apply normalization. In Oracle APEX I created tables with primary keys, foreign keys, NOT NULL and UNIQUE constraints, changed them with ALTER TABLE and DROP TABLE, and managed records with INSERT, UPDATE and DELETE. I retrieved data with SELECT using aliases, WHERE, LIKE, ORDER BY, DISTINCT and aggregate functions, then GROUP BY, HAVING, subqueries and the join types INNER, LEFT, RIGHT, FULL OUTER, NATURAL and USING.

What was most challenging?

Outer joins and queries that compare a value with an average were the hardest, along with choosing which table goes on the left or right of a join. Normalization and supertype/subtype design were also difficult at first.

How did I overcome the difficulties?

I ran each query in Oracle APEX, checked the result against the table data, and confirmed changes with DESCRIBE or SELECT *. When a statement failed, I read the error, fixed it and ran it again. I also learned that a result with no rows can still be correct.

How will I apply what I learned?

As a Business Analytics student I will use SQL to collect data from several tables, combine it with joins and summarize it for reports. I will apply CRUD and database design in my Flutter and Firebase work and other projects.
